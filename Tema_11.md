## Задание 2
Класс итератор с гибкой настройкой и удобным применением

```python
class CountDown:
    def __init__(self, start):
        self.count = start + 1
    
    def __iter__(self):
        return self
    
    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count

if __name__ == '__main__':
    counter = CountDown(5)
    for i in counter:
        print(i)
```

![Результат](https://github.com/notybre/SoftwareEngineering/blob/Tema_11/pic/l%20\(2\).PNG)

**Вывод:** Класс CountDown реализует итератор через методы __iter__() и __next__(). можно контролировать логику обхода, завершение итерации и внутреннее состояние счётчика. В отличие от простого списка, этот итератор не хранит все значения сразу, а создаёт их по мере запроса.

## Задание 5
Такой же счетчик, как и B первом задании, только это генератор и
использует yield 

```python
def countdown(count):
    while count >= 0:
        yield count
        count -= 1

if __name__ == '__main__':
    counter = countdown(5)
    for i in counter:
        print(i)
```

![Результат](https://github.com/notybre/SoftwareEngineering/blob/Tema_11/pic/l%20\(5\).PNG)

**Вывод:** Функция countdown() реализует генератор с помощью ключевого слова yield. Каждый вызов yield приостанавливает выполнение функции и возвращает текущее значение, сохраняя контекст для следующего вызова. Такой подход позволяет эффективно создавать последовательности без предварительного хранения всех элементов, как в классических итераторах.

## Задание 1
Вас никак не могут оставить числа Фибоначчи, очень уж они вас
заинтересовали. Изучив новые возможности Python вы решили
реализовать программу, которая считает числа Фибоначчи при
помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте
функцию fib(n), генерирующую п чисел Фибоначчи с
минимальными затратами ресурсов. Для реализации этой функции
потребуется обратиться к инструкции yield (Она не сохраняет B
оперативной памяти огромную последовательность, а дает
возможность “доставать” промежуточные результаты по одному).
Результатом решения задачи будет листинг кода и вывод в консоль с
числом Фибоначчи от 200. 

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

if __name__ == '__main__':
    for num in fib(200):
        print(num, end=' ')
```

![Результат](https://github.com/notybre/SoftwareEngineering/blob/Tema_11/pic/s%20\(1\).PNG)

**Вывод:**
Использование `yield` позволяет создавать **ленивый генератор**, который возвращает по одному значению за раз без хранения всей последовательности в памяти. Это делает генераторы идеальным инструментом для работы с большими наборами данных — в отличие от списков, они экономят ресурсы и работают быстрее.

## Задание 2
К коду предыдущей задачи добавьте запоминание каждого числа
Фибоначчи в файл “fib.txt”, при этом каждое число должно
находиться на отдельной строчке. Результатом выполнения задачи
будет листинг кода и скриншот получившегося файла

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

if __name__ == '__main__':
    with open("fib.txt", "w", encoding="utf-8") as f:
        for num in fib(200):
            f.write(str(num) + "\n")
            print(num, end=' ')
```

![Результат](https://github.com/notybre/SoftwareEngineering/blob/Tema_11/pic/s%20\(2\).PNG)

**Вывод:**
Генератор передаёт числа Фибоначчи напрямую в файл построчно, не занимая оперативную память.
Такой подход демонстрирует **возможность потоковой обработки данных** — генератор выдаёт значения по мере необходимости, а запись идёт сразу на диск. Это сочетает преимущества итераторов и работы с файлами, обеспечивая эффективность и надёжность.

## Общий вывод

Итераторы и генераторы это инструменты, которые позволяют эффективно работать с последовательностями данных, особенно при больших объёмах информации.

- Итераторы это объекты, реализующие методы __iter__() и __next__(). Они выдают элементы по одному за раз и запоминают своё состояние между вызовами. Такой подход позволяет экономить память, поскольку все элементы не хранятся в оперативной памяти одновременно.

- Генераторы это спеиальные функции, использующие ключевое слово yield. Они автоматически создают итераторы и возвращают значения по мере запроса.

- компактная форма записи генераторов, но без предварительного создания списка в памяти называется генераторными выражениями.

- Итераторы обеспечивают контроль над процессом обхода, а генераторы делают код лаконичным и эффективным. Вместе они формируют основу “ленивых вычислений” в Python, что особенно важно для оптимизации производительности и экономии ресурсов.

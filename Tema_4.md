## Задание 1

**Подробный комментарий к коду**

```python
from datetime import datetime      # импортируем класс datetime для работы с датой и временем
from math import sqrt              # импортируем функцию sqrt (квадратный корень) из модуля math

def main(**kwargs):                 # определяем функцию main, которая принимает произвольное количество именованных аргументов
    for key in kwargs.items():      # перебираем все пары (ключ, значение) словаря kwargs
        result = sqrt(key[1][0] ** 2 + key[1][1] ** 2)  # вычисляем длину вектора
        print(result)               # выводим результат вычисления

if __name__ == '__main__':          # проверка, что программа запущена напрямую, а не импортирована как модуль
    start_time = datetime.now()     # сохраняем текущее время перед выполнением функции
    main(                           # вызываем функцию main, передавая ей несколько аргументов-списков
        one=[10, 3],
        two=[5, 4],
        three=[15, 13],
        four=[93, 53],
        five=[133, 15]
    )
    time_costs = datetime.now() - start_time   # вычисляем время выполнения программы
    print(f"Время выполнения программы - {time_costs}")  # выводим затраченное время
```

**Файл 1: `triangle.py` (формула Герона)**

```python
import math

def heron_area(a, b, c):
    p = (a + b + c) / 2             # полупериметр
    return math.sqrt(p * (p - a) * (p - b) * (p - c))  # формула Герона
```

**Файл 2: `main.py` (взаимодействие с пользователем)**

## Вывод

Функции - это блоки кода, которые можно вызывать многократно. Они помогают избегать дублирования и упрощают работ программ.

Модули - это отдельные файлы с функциями, которые можно подключать в код с помощью import. Это позволяет расширить функционал программы.

if __name__ == "__main__": - конструкция, которая указывает, что код внутри неё выполнится при прямом запуске файла, а при импорте модуля этот код не запустится. Это нужно для разделения логики программы и функций.

*args - позволяет функции принимать произвольное количество аргументов. Внутри функции они представляют собой кортеж.

**kwargs - позволяет функции принимать произвольное количество именованных аргументов (ключ=значение). Внутри функции они представляют собой словарь.

Кортежи (tuple) - это упорядоченные данные. Они полезны, когда нужно хранить фиксированные наборы значений, которые не должны изменяться.
